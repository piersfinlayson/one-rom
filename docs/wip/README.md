# Work in progress

Documents in this directory are proposals and drafts.  They describe how
something might work, not how it works today.  Nothing described here is
implemented unless the document says it is.

They live apart from `docs/` so that everything in `docs/` can be read as a
description of One ROM as it is.

A document leaves here in one of two directions.  It moves to `docs/` when what
it describes is real and worth keeping, or it is deleted when it is neither.
