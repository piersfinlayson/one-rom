# Fire 40 Rev B

A variant of the 40 pin version.  Adds a neo-pixel LED..

**Has components on both sides of the board.**

Changes from fire-40-a:
- Adds a neo-pixel LED, GPIO 44, alongside the status LED at GPIO 45 (which changed for consistency with other RP235XB based boards).
- Address and CS pins have been laid out differently to allow more efficient use of flash for some image types.
