# Which component each source path belongs to, longest prefix first.
#
#   <path prefix>    <id>    <component name>
#
# The id names the badge JSON that ci/coverage-report.sh --badges writes, and
# it is what appears in the badge URLs in README.md.  The name heads the
# subtotal row in the report.  Rename an id and the README's URL has to move
# with it - the old badge 404s, which is how you find out.
#
# Anything instrumented that matches no prefix is reported under "Ungrouped"
# rather than dropped.  That is deliberate: a new component appearing in the
# report is the point, and silently omitting it would defeat the exercise.
