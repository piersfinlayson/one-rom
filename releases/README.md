# Releases

The files in this directory were generated by the [GitHub release
workflow](../.github/workflows/release.yml) up to and including the v0.6.x
releases.

They are read by the One ROM Web programmer to discover the pre-built firmware
image artifacts published with those releases, so they can be downloaded and
programmed.

From v0.7.0 onwards the release workflow no longer updates this directory.
v0.7.0+ releases publish only the base One ROM firmware - a single image that
covers every Fire board - and no longer produce per-board pre-built images. The
existing files here are retained so the Web programmer can still offer the
pre-built images from earlier (v0.6.x and older) releases.
